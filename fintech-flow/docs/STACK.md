# Justificativa da Stack
- **JavaScript fullstack:** uma linguagem no servidor e no cliente reduz curva de aprendizado e permite compartilhar regras de validação.
- **Node.js/Express:** I/O assíncrono, ideal para APIs REST; ecossistema maduro (JWT, Zod, Swagger).
- **React + Vite:** interface componentizada, build rápido e responsiva para web/mobile.
- **SQLite:** relacional, simples de configurar, suporta constraints e auditoria; migrável para PostgreSQL.
- **Fintechs na Grande Florianópolis** adotam Node/React pela agilidade e integração multiplataforma.
